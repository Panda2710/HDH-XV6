# HDH-XV6
# Chương trình du:
- Cách chạy:
du . : Chỉ in dung lượng của các thư mục
du . -s: Chỉ in tổng dung lượng của thư mục cha
du . -a: In chi chi tiết dung lượng của cả file và thư mục
# Chương trình diff:
- Cách chạy:
diff [fileName1] [fileName2] : In ra những dòng khác nhau giữa 2 file
diff [fileName1] [fileName2] -q : Chế độ im lặng (quiet), chỉ in ra 2 file giống hay khác nhau hay không
*** Trong trường hợp cả 2 file đều giống nhau thì cả 2 cách chạy trên đều không in ra gì cả.
